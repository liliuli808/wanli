# 碗里 App UI 重设计（暖调食欲系 · 全量重做）

日期：2026-10-29
状态：已确认（方向 / 粒度 / 导航 / 交付终点均由用户在澄清问题中选定）

## 1. 背景

2026-07-29 那一轮「清新自然系」（鼠尾草绿 + 米白 + 衬线标题）已全量落地到 Compose。本轮用户判定风格不再合适，要求**推倒重来**：换一整套视觉语言，并且**连信息架构与版式一起重做**，最终产出要装到 Redmi K50 上。

本轮与上一轮的关系：视觉体系完全替换，不复用旧配色/字体/卡片形态；功能边界保持（不加新业务能力）。

## 2. 已确认决策

| 决策点 | 用户选择 |
|---|---|
| 重设计动因 | 换风格：推倒重来 |
| 视觉方向 | **暖调食欲系**：番茄红 `#E4572E` + 奶油白 `#FFF8F2` + 焦糖橙 `#F2A541` + 24dp 大圆角 |
| 重做粒度 | 连布局一起重做（信息架构 + 每屏版式均可重排） |
| 底部导航 | **5 Tab + 中央导入**：首页 / 发现 / ⊕ / 消息 / 我的；厨房与忌口收进「我的」 |
| 交付终点 | Stitch 全套稿 + Compose 落地 + 打包安装到手机 |
| Stitch 项目 | 新建「碗里 · 暖调食欲系」，不复用旧项目 |

## 3. 视觉语言（设计系统 Token）

| Token | 取值 | 用途 |
|---|---|---|
| primary | `#E4572E` 番茄红 | 主按钮、选中态、中央导入 FAB |
| onPrimary | `#FFFFFF` | |
| primaryContainer | `#FFDBD0` / on `#410E00` | 浅红底衬、选中 chip |
| background | `#FFF8F2` 奶油 | 全局底 |
| surface | `#FFFFFF` | 卡片 |
| surfaceVariant | `#F5E9E1` | 分组底、输入框 |
| secondary | `#F2A541` 焦糖橙 | 评分星、徽章、次级高光 |
| secondaryContainer | `#FFE0B2` / on `#2B1700` | 「N 人做过」徽章 |
| onSurface | `#2B1A12` 暖墨棕 | 正文 |
| onSurfaceVariant | `#7A6559` | 次要文字 |
| outline | `#E6D5C9` | 分隔线、描边 |
| error / success / warning | `#B3261E` / `#4F7A3F` / `#B26A00` | 状态语义 |

- **圆角**：卡片 24dp、图片 24dp、按钮 16dp、chip / 头像 / 徽章全圆
- **阴影**：暖色柔阴影 `rgba(228,87,46,0.10)`，y=8 blur=24；禁止冷灰阴影
- **字体**：标题思源黑体 Bold（Noto Sans SC）／正文 Noto Sans SC Regular；标题 28–32sp，正文 14–15sp，行高 1.5
- **图标**：Material Symbols Rounded；选中态填充，未选中线性；全面弃用 emoji
- **图片**：Feed 卡 4:3 满宽；发现页瀑布流原始比例；做过照片 1:1
- **动效**：卡片按下缩放 0.98、Tab 切换淡入、FAB 展开为导入弹层
- **深色模式**：本期不做

## 4. 信息架构

```
首页 Feed   发现   (⊕)   消息   我的
```

| Tab | 职能 |
|---|---|
| 首页 | 社区「做过」动态 + 新版本动态；顶部搜索式导入入口 + 右上铃铛；下拉刷新 |
| 发现 | 双列瀑布流，分类 chip + 最新/最热切换 |
| ⊕ | 点击展开底部导入 Sheet（B 站链接 → 解析中 → 结果预览） |
| 消息 | 四类聚合：评论回复 / 纠错审核结果 / 有人改编了你的版本 / 系统 |
| 我的 | 身份区（头像+昵称+简介）→ 做过照片墙 → 我的版本 → 我的收藏 → 设置（内含厨房与忌口） |

厨房与忌口从一级 Tab 降为「我的 → 设置」下的两个页面；路由保留，仅改入口位置。

## 5. 逐屏设计要点

| 屏幕 | 关键设计 |
|---|---|
| 首页 Feed | 4:3 满宽食物图 + 24dp 圆角卡片；作者行（头像/昵称/时间）+ 焦糖橙「N 人做过」徽章 + 一句话反馈；穿插新版本动态卡（改编链 chip） |
| 发现 | 双列瀑布流、错落高度；卡片只留图 + 标题 + 作者头像 |
| 导入 Sheet | 底部 Sheet，顶部圆角 28dp，输入框 + 粘贴按钮 + 「解析」主按钮；解析中骨架 + 进度文案 |
| 消息 | 顶部四段筛选 chip（全部/回复/审核/系统）；列表项左侧彩色圆形图标底 |
| 我的 | 品牌渐变头图（番茄红→焦糖橙，低饱和）+ 头像压边 + 统计三项（做过/版本/收藏）+ 3 列照片墙 |
| 菜谱详情 | 顶部满宽大图（折叠视差）+ 悬浮返回；标题区 + 作者行 + 评分徽章；食材卡 + 步骤时间轴（大序号圆点）；底部固定「厨房适配」主按钮 |
| 版本谱系 | 图形化树：根节点 UP 主原版，分支节点带作者头像，2dp 暖色连接线 |
| 厨房设置 | 调料网格卡（有/无 双态）+ 分类分组 + 顶部说明卡 |
| 忌口 | 分组 chip 网格 + 自定义输入 |
| 适配结果 | 「改了什么」对照卡（原 → 新 高亮差异）+ 重写步骤列表 |
| 校对 / 编辑 | 分区折叠表单，圆角输入框，底部固定保存 |
| 登录 | 品牌化：大字标题 + 番茄红主按钮 + Turnstile 区域 + 协议勾选 |
| 次级列表 | 我的改编 / 待审核纠错共用列表模板：缩略图 + 标题 + 状态 chip |
| 空 / 加载态 | 统一三式：SkeletonCard / EmptyState / 错误+重试 |

## 6. 执行计划

1. **Stitch**：新建项目「碗里 · 暖调食欲系」→ `create_design_system` → 按序生成 13 屏 → 每 2–3 屏抽查 → 导出 HTML 作为视觉基准
2. **Compose 落地**：
   - 重写 `presentation/theme/`（Color / Shape / Type）
   - 新增 `presentation/components/`：FoodCard、CenterImportFab、AppBottomBar、RatingBadge、StepTimeline、PhotoWall
   - 逐屏改造，导航改 5 Tab + 中央 FAB，厨房/忌口入口迁至「我的」
3. **打包装机**：`config.properties` 改 `https://api.susie.one/api/v1/` → release 签名包 → adb 安装到 Redmi K50
4. **验证**：`gradle_build.sh` + `gradle_test.sh` 全绿；装机后手工走一遍主流程

## 7. 非目标

- 点赞、关注关系、私信、个性化推荐
- 深色模式
- 大字烹饪模式（仍按原计划独立排期）
- 后端新接口（本轮纯前端换新；若实现中发现缺字段再单独提）

## 8. 风险与对策

| 风险 | 对策 |
|---|---|
| Stitch 中文渲染与字体回退不稳定 | 设计稿以版式/配色为准，文案以 Compose 为准 |
| 13 屏一次性生成易跑偏 | 每 2–3 屏截图核对，跑偏用 `edit_screens` 修正 |
| 全量重写 Compose 影响既有功能 | 先改 theme + 组件层，再逐屏替换；每屏改完跑一次 build |
| 暖色调对比度不足 | 正文用 `#2B1A12`，主按钮文字用纯白，正文对比度 ≥ 4.5:1 |
