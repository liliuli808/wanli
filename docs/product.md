# “碗里” (WanLi) - 产品定义与核心价值文档 (product.md)

## 一、 产品定位与核心价值

“碗里” 是一款专注于**家庭烹饪场景**的独立 Android 客户端与 Go 后端系统。它并非普通的静态菜谱平台，而是一个以**“视频一键结构化”**为入口，以**“社区开放共创”**为内容增长引擎，以**“个人厨房智能适配”**为核心体验的智能做饭助手。

### 核心痛点解决
- **视频学做菜痛点**：用户在 B 站观看美食视频时，需要频繁地暂停、倒退、在纸上或备忘录中手写食材用量、翻看评论区寻找步骤。在做菜时手忙脚乱。“碗里”通过 AI 识别视频字幕，一键将其转化为**结构化、带时间戳标签、可分步操作**的电子菜谱。
- **菜谱不适用痛点**：传统菜谱要求食材极度精确，但用户厨房里往往缺盐少醋，或者家中有忌口（如：控糖、不吃香菜、花生过敏）。“碗里”提供**一键厨房适配功能**，只记录厨房“有没有”，根据库存和忌口由 AI 重写生成一个定制版本的做菜步骤。
- **内容割裂痛点**：传统的菜谱和视频是割裂的。“碗里”不仅保留原视频，每一个做菜步骤都可以一键跳转回视频对应的精彩时间点。

## 二、 核心版本衍生逻辑 (核心业务特色)

“碗里”建立了一套独特的三层菜谱模型，确保内容的高质量与个性化的完美结合：

```text
       ┌────────────────────────┐
       │   [ 视频 & 字幕 ]      │
       └───────────┬────────────┘
                   │  AI 解析 (一键装碗)
                   ▼
       ┌────────────────────────┐
       │   1. 来源解析版 (公开)  │ ◄─────── 提交纠错建议 (发布者审核)
       └───────────┬────────────┘
                   ├──────────────────────────────┐
                   │ 派生改编                     │ 厨房适配 (用户手动)
                   ▼                              ▼
       ┌────────────────────────┐      ┌────────────────────────┐
       │   2. 社区改编版 (公开)  │      │   3. 个人适配版 (私有)  │
       └────────────────────────┘      └────────────────────────┘
         (如：空气炸锅版、不辣版)         (默认私有，可选择公开发布，
                                         但公开后不可被其他用户再改编)
```

1. **来源解析版 (公开)**：
   - 必须完全忠实于原视频和字幕。
   - 普通用户无法直接覆盖，但可提交“纠错申请”，由该版本的发布者（即提交解析视频的用户）进行审核。
2. **社区改编版 (公开)**：
   - 任何人都可以点击“改编”，在来源解析版（或其他改编版）的基础上派生出新版本。
   - 页面会清晰显示派生树（如：*“改编自 UP 主 xxx 的 经典红烧肉”*），并支持版本对比。
3. **个人适配版 (私有 -> 可公开)**：
   - 用户点击“适配我的厨房”后生成，默认私有。
   - 用户可以一键将其“公开分享”到社区。
   - **特殊约束**：为避免社区版本树无限膨胀导致关系极度混乱，**公开的个人适配版属于终端节点，不支持被其他用户再次“改编”**。

## 三、 明确不做的范围 (Non-Goals)

为了保证 MVP 首版在有限的时间内稳定交付，以下功能明确不在本期开发范围内：
1. **自动库存数量管理**：不记录“还剩 200ml 酱油”，只记录“有/无”酱油。
2. **多终端同步**：首版仅支持原生 Android 端，不提供 iOS、小程序或 Web 前端（Web 仅限内部后台管理）。
3. **无字幕视频 ASR 语音转写**：字幕获取失败时直接标记失败，不接入低质量、高成本的第三方语音识别服务，以确保菜谱来源的高准确度。
4. **个性化智能推荐流**：首版不设计复杂的协同过滤和推荐算法，社区内容以关注、最新发布、最热改编、分类筛选为主。
5. **智能厨房硬件联动**：不与任何智能烤箱、冰箱等物联网硬件对接。
6. **付费菜谱与电商系统**：首版完全免费，无商品购买、广告及付费解锁功能。
